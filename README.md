# 🚀 Barium (for Minecraft 26.3)
Barium is a lightweight performance optimization mod for Minecraft 26.3. It improves rendering efficiency, chunk loading, and overall game performance while preserving visual quality. Whether you're playing in modded environments or large vanilla worlds, Barium helps ensure smoother gameplay.

## ✅ Key Features:
Improved chunk and block rendering

Reduced lag spikes and faster world loading

Compatible with Fabric modpacks

Ideal for enhancing performance in demanding worlds
